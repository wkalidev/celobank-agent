This is an early-stage, community token for a real, working open-source project.

## 🎯 Purpose of the $CBA Token

The token serves three functions, in order of priority:

1. **Reward** — Early supporters, contributors, and testers who believe in financial inclusion via DeFi
2. **Fund** — Ongoing development of the SDK and agent infrastructure
3. **Govern** — Future direction of the protocol once the community is large enough

## 🔐 Vesting — Founder Allocation (15%)

- **Month 0–12**: Full lock. Zero tokens released.
- **Month 13–36**: Linear release over 24 months (~3,125,000 CBA/month)
- **Why**: Align incentives with long-term project health, not a quick exit.

No vesting is enforced by a smart contract today (the project is too early). This is a public commitment, visible on GitHub.
